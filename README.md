# Infodose for Windows

Official Windows app for [Infodose](https://infodose.io), the question bank for medical licensing exams.

**Download:** see the latest release on the Releases page, or use the download page at https://infodose.io/app.

- Windows 10 or 11, 64-bit.
- Windows may show "Windows protected your PC" the first time, because the installer is not code-signed yet.
  Click **More info**, then **Run anyway**.
- Inside the app, screenshots and screen recordings show a blank window. This protects the questions.
